中国生态多模态 Agent 模型API 正式可用开放权重社区许可证

MiniMax M3.1 Flash：先上线 API，后发布权重

10 月 19 日 M3.1 Flash 上线 MiniMax API、M Plan 与 MiniMax Code；10 月 23 日官方 Hugging Face 仓库初始化并放出权重。模型卡列出约 428B 总参数、每 token 23B 激活，支持文本、图像、视频输入与最高 1M 上下文。

为什么重要同一模型同时覆盖低价托管 API 与可带走权重，给成本敏感的 Agent、电脑操作和多模态工作流更多部署选择。
对实践的影响API 价为每百万 token 输入 $0.15、输出 $0.60、缓存输入 $0.015；自托管则面对约 428B 规模与较高显存门槛。
许可证、基准与正确分类
已核实事实
  • 模型卡：原生多模态 MoE，1M 上下文；推荐 SGLang、vLLM、TokenSpeed。
  • 许可证不是 Apache / MIT：商用需显示 “Built with MiniMax M3.1-Flash” 并通知 MiniMax；相关产品年收入超过 2,000 万美元需事先书面授权。
厂商自述 / 局限
  • 速度、节省 70% 与多数基准是 MiniMax 报告；不同 harness 不宜横向排名。
  • 官方模型卡本身把 Transformers 等部分集成写为进行中；生产前应验证当前 runtime 支持。

Agent 工作台本地 Mini App桌面端已可用社区仓库

MiniMax Code 推出可持续存在的 Mini App

Mini App 是带前端与 Node.js 后端的长期应用，可作为插件安装，也可与 Agent 互相调用；页面、数据目录、Hosted MCP 与 Agent API 由桌面 Host 管理，/miniapp-creator 可从一句描述生成并截图检查。

为什么重要Agent 产物从一次性对话 / 静态 HTML 变成持续更新、可被人和 Agent 共同操作的本地工作台。
对实践的影响适合指标面板、Git 历史、3D 工具等重复工作；当前只在 MiniMax Code 桌面 macOS / Windows 的本地 session。
权限模型与供应链风险
已核实事实
  • 凭证由 Host 保存，插件 / 页面不可直接访问；连接器与 Agent 权限需在 manifest 声明。
  • 页面发给 Agent 的内容先进入输入框供用户审阅。
安全提醒
  • Mini App 代码以本机用户权限执行；官方明确提示只安装可信来源包。
  • 社区 App 源码仓库开放，不等于每个第三方插件都已安全审计。

趋势观察与行动建议

由本周多个一手来源共同支持的编辑判断。
01 · 路由可观测性

给每次响应记录“实际模型”

Notion Auto、Google Cloud Model Garden 与 Foundry Toolkit 都把路由推向生产。建议日志至少记录请求模型、实际服务模型、版本、token、延迟、工具调用和重试；否则成本异常与质量回退无法复盘。

02 · 数据处理主体

把托管方写进架构决策记录

Claude 在同一 Google Cloud 内仍可由 Anthropic 或 Google 处理数据；OpenAI 模型则处于另一条私有预览路径。采购表应增加 data processor、合同条款、区域驻留、CMEK / VPC 与新功能延迟字段。

03 · 许可分层

权重可下载不等于可自由商用

MiniMax M3.1 Flash、Spark‑X2.6 与 Carbon‑X 的交付形式相似，许可却从附收入门槛的社区条款到 Apache‑2.0。落地前把权重、源码、数据、商用义务、品牌标识与再分发逐项核验。

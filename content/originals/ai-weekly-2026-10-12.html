本周主线：AI 正从“给答案”进一步转向“生成界面、调用工具并完成任务”，与此同时，权限、隔离、许可证与发布状态正在成为产品能力的一部分。

值得关注的不只是模型“更强”，而是输出层、执行层和治理层正在同时产品化。

本周最值得关注的 3 件事

按对开发与产品决策的影响排序，不是热度榜。
01 · 交互形态

GPT‑6 把“界面”变成回答本身

Intelligent UI 可在对话中组合文本、图形、表单、按钮和交互工具，意味着前端不再总是预先写死。

已开始全球滚动推出；不同方案使用 Sol / Luna。
02 · 执行边界

Agent 开始拥有身份，也开始被隔离

Google 强调持久 Agent 与专属身份；Windows 的 MXC 则把文件、网络权限落实到运行时容器。

能力与治理一起进入平台层，而非只靠提示词。
03 · 开放生态

开放权重发布越来越“分阶段”

Qwen Turbo 权重已可下载；Beam 与 Mistral Large 4 只是预览或候补，权重仍待月底。

“已宣布”不等于“已开放权重”，更不等于“开源”。

开放生态早期访问 / 权重未发布

Reflection 发布 Beam 预览，但“开放权重”仍是承诺

Beam 是 501B 总参数、23B 激活参数的稀疏 MoE，面向编码、推理和 Agent 工作负载；目前仍在最终红队与评估阶段，仅开放候补/早期访问。

为什么重要美国团队试图以更低激活参数和可自托管路线补上开放权重模型生态。
对实践的影响现在可以评估 API 与文档，但不能把它列入“可离线部署”清单。
限制、口径与证据
已核实事实
  • 官方称月底发布权重、技术报告、模型卡和开发者制品。
  • 计划使用 Apache 2.0；当前未在官方 Hugging Face 组织公开权重。
不要误读
  • 性能表主要来自厂商自测，尚不能当作独立结论。
  • “open-weight model”是产品定位，不代表权重已交付。

大模型 / 多模态公开预览 API权重月底发布

Mistral Large 4 进入公开预览

Mistral 公布 1T 总参数、52B 激活参数的原生多模态 ML4，可通过预览 API 试用；权重计划月底发布。

为什么重要欧洲厂商把“主权部署、多语言、多模态、网络安全”合并成一套企业定位。
适用与限制适合先做接口适配与业务评测；自托管、许可细节和最终模型卡仍需等待。
事实与厂商自述
已核实事实

  • 性能、网络安全和企业基准数字主要来自 Mistral 及其选定评估。
  • 正式权重、许可证和可复现部署成本尚未交付。

10 月 6 日
安全访问治理需资质审核

Anthropic 扩展网络安全能力验证计划

CVP 被拆成 Defense、Red Team、Specialized 三档，合格安全团队可获得更少拦截的模型能力，但需验证资质并接受不同的数据和控制要求。

为什么重要厂商开始以“用户身份 + 场景 + 控制条件”而非统一拒绝策略分发高风险能力。
适用与限制适用于授权防御、红队和关键基础设施测试；不是普通开发者的通用解锁入口。
关键边界
已核实事实
  • Defense 档覆盖 SOC、事件响应、恶意软件分析等防御工作。
  • Red Team 档仅限获授权目标；Specialized 档审核最严格。
隐私与数据
  • 计划通常要求数据保留以监测滥用。
  • 零数据保留仅在特定模型/资格下可用，EFS 仍在未来推出。

10 月 6 日
开发者 API决策工作流Public Beta

OpenAI 推出 Decisions API 公测

新端点把文本或图像转成 predicate、choice、score 三类带类型的答案，可用于分类、路由、排序和审核。

为什么重要把“让模型输出 JSON”进一步收束为专用、可校验的决策接口。
对实践的影响适合批量分类、风险打分、工单路由；复杂生成和工具调用仍应使用 Responses API。
能力、成本与限制
已核实事实
  • 仅支持 gpt-6-luna，端点为 POST /v1/decisions。
  • 官方称约比 Responses API 快 10 倍；这是厂商测量，需自行回归。
上线建议
  • Public Beta，接口和行为仍可能变化。
  • 概率不等于经过业务校准的真实风险；高风险决策仍需阈值验证与人工复核。

GPT‑6 与 Intelligent UI 面向更多 ChatGPT 用户推出

为什么重要模型输出从“内容”升级为“可操作界面”，解释、比较、规划和小工具可直接在对话内完成。
产品启示需要把 UI 组件安全、无障碍、状态管理与数据来源纳入模型输出评测。

  • 官方承认模型的设计判断仍需改进。
  • 动态界面可能产生错误交互或误导性视觉，不能替代来源与校验。

Claude Haiku 5.5 正式上线，瞄准高频子任务

Anthropic 将新 Haiku 定位为摘要、压缩、数据库查询、分类、客服、浏览器操作和子 Agent 等成本敏感工作负载。

为什么重要Agent 架构正从“全程用旗舰模型”转向按任务路由，成本优化落到模型分层。
成本与限制≤100K 提示时为 $0.10 输入 / $0.50 输出每百万 token；超过 100K 后升至 $0.50 / $2.50。

已核实事实

  • Sonnet 5.5 缓存读取同步降至 $0.10 / 百万 token。
厂商自述
  • “平均运行成本低 75%”包含 tokenizer 与任务 token 使用变化，不能只用单价外推。

10 月 7 日
本地推理Agent 沙箱MXC 已 GA其余分阶段推出

Windows 把本地模型、智能路由与 Agent 隔离放到同一平台

Microsoft Execution Containers（MXC）在 Windows 11 正式可用，可在运行时限制 Agent 的文件与网络访问；llama.cpp 接入 Windows ML，Copilot 本地上下文与本地动作将在未来数月推出。

为什么重要Agent 安全边界下沉到操作系统：权限不再只是应用层的“请不要访问”。
对实践的影响Windows Agent 可用容器、身份、审计和本地推理降低数据外发，但功能受设备、市场与硬件影响。
正式能力与预告分界
本周已发生
  • MXC GA；多款 Agent 已支持，另有产品宣布后续接入。
  • Windows ML 宣布 llama.cpp 支持。
尚未普遍可用
  • Copilot 本地上下文/动作/模型预计未来数月逐步推出。
  • HydraFusion 本地路由为 10 月稍晚的实验预览。

10 月 8 日
企业 Agent多模型路由受限推出 / 未标明 GA

Google 公布“通用工作 Agent”

Gemini Agent 计划跨 Gmail、Drive、Docs、Sheets、Calendar、CLI、Microsoft 365 与 Slack 工作，并可在 Gemini 与 Anthropic Claude 等模型之间路由；Coworker Agent 还能拥有独立邮箱与存储身份。

为什么重要企业 Agent 从插件式助手走向持久身份、长期记忆、事件触发和多 Agent 编排。
风险与门槛跨系统权限与长期记忆提高泄露和越权风险；应优先设计最小权限、审批、撤销和审计。
可用性与事实边界
官方明确
  • 支持工具/技能注册表、MCP、成本上限和模型路由。
  • 官方文章列出多家早期客户和工作流。
官方未明确
  • 主公告未列统一公开 GA 日期和标准价格。
  • 因此本期不把它写成面向所有用户的正式可用产品。

10 月 8 日
政策高风险使用11 月 12 日生效

Anthropic 更新 Usage Policy，补上 Agent 与物理动作边界

新政策集中禁止欺骗活动，细化监控、武器、选举和高风险用途，并要求可能造成伤害的自主硬件具备可观察、可停止和断连安全状态。

为什么重要模型政策开始覆盖“长期自主执行”和“连接现实设备”，而不只是内容生成。
对产品的影响健康、法律、金融、就业和基本服务等场景仍需有权复核的人工，并告知受影响者使用了 AI。
生效时间与行动项
已核实事实
  • 公告日为 10 月 8 日，政策 11 月 12 日生效。
  • 移除“个性化投票/竞选定向”的一刀切禁令，但欺骗和隐私滥用仍禁止。
建议
  • 在生效前重新审核用途分类、人工复核、告知与日志。
  • 硬件 Agent 增加急停、断连安全态和责任人。

为什么重要中国图像模型把“可下载权重 + 云 API + Diffusers 工作流”同时交付，便于快速做成本与部署取舍。

趋势观察与行动建议

由本周多个一手来源共同支持的编辑判断。
01 · 交互层

把“生成 UI”当成新的输出类型

OpenAI 的 Intelligent UI 与 Google 的通用 Agent 都在弱化固定聊天框。产品团队应新增：组件可访问性、交互失败、视觉误导、状态恢复与来源呈现测试。

02 · 权限层

把 Agent 权限从提示词移到系统边界

MXC、Gemini Agent 身份与 CVP 分级说明同一方向：为读、写、执行、网络和高风险域分别授权，并确保可以撤销、审计和人工中止。

03 · 供应链

模型目录必须记录“发布状态”

建议在内部 registry 增加 stage、weights_available、license、region、data_retention 与 verified_at，避免把预览或候补当成生产依赖。
